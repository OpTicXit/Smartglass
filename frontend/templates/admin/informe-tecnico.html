    Cómo leer este informe

    Cada bloque dice de dónde salen sus datos con una etiqueta junto al título. El CO₂ de SmartGlass siempre se estima con factores de emisión; no se mide.

    • Azul: los datos de la plataforma y lo que predice el modelo.
    • Ámbar: el valor con el que se compara y la proyección.
    • Línea discontinua y banda: la proyección y su rango probable.
    • Ningún color de las gráficas es una alerta.
    Decisiones al construir el modelo

    Qué se decidió al crear el modelo predictivo de CO₂ y por qué.

    1. Datos sintéticos y reproducibles

      No hay registros de una vidriería real, así que se generaron 10.000 piezas a partir de factores de emisión documentados, con la semilla fija 42: cualquiera obtiene el mismo dataset.

    2. Sin la masa como variable

      La masa sale de la misma fórmula que el CO₂ (área × espesor × 2,5). Incluirla le daría la respuesta al modelo e inflaría las métricas, así que se deja fuera.

    3. Seis variables con One-Hot

      Tipo de vidrio y proceso se codifican con One-Hot; área, espesor, calcín y energía por kilo entran como números.

    4. 80 % para entrenar, 20 % para probar

      La partición es aleatoria con semilla 42 (8.000 y 2.000 registros), y se suma una validación cruzada de 5 particiones para comprobar que el resultado no depende del corte.

    5. Random Forest de 200 árboles

      Se comparó con dos referencias: la media (MAE 99,87 kg) y una regresión lineal (MAE 31,84 kg). Random Forest capta que el tipo de vidrio cambia el efecto del tamaño y baja el error a 13,52 kg.

    6. Algo de sobreajuste aceptado

      En entrenamiento logra R² 0,9947 y en prueba 0,9613. Se aceptó porque la validación cruzada es estable (0,9615 ± 0,0036).

    7. Todavía no cotiza

      El cotizador sigue usando fórmulas deterministas: el modelo pide proceso, energía y calcín que el formulario no recoge, y conoce 20 tipos frente a 7. Se validará con datos reales del piloto.

    8. Proyecciones con un modelo aparte

      El CO₂ futuro se proyecta con tendencia y estacionalidad semanal y anual (mínimos cuadrados), no con el Random Forest, y siempre con su rango probable.

    Fuente: Our World in Data, con datos del Global Carbon Budget. Es el CO₂ fósil total de cada país, no las emisiones del vidrio ni de SmartGlass.
